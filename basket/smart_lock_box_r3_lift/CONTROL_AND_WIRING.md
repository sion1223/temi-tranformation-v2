# 전원·회로·동작 조건

이 문서는 R3-LIFT용 **회로 및 제어 연결 설계**다. 실제 보드용 승강 펌웨어를 제공하거나 컴파일·구동한 결과가 아니다. R3의 인증·잠금·무게 판정 코드를 통합할 때 아래 핀맵으로 수정해야 한다. 기존 R3 `.hex`는 새 핀맵과 호환되지 않는다.

## 전원

안정화12V/2A 외부 어댑터 → 메인T1A → SB310 역극성 보호 →12V 버스. 버스에서 (1)T315mA→DRV8876 VIN→PQ12, (2)잠금 솔레노이드, (3)D24V10F5→5V 논리/센서로 분기한다. 모터0.21A 정지전류, 잠금 약0.35A, 논리 여유를 합쳐 입력을 설계했다. 실물 기동전류·퓨즈 시간특성·DC 차단정격은 검증한다. 로봇 전원포트에 임의 연결하지 않는다.

- PQ12-S 핀2·3은 DRV8876 OUT1·OUT2. 극성을 바꾸면 역방향이다. 선택한 S형에는 내부 끝단스위치가 있으며 P형과 배선·종료 방식이 다르다.
- DRV8876 PMODE=GND로 고정하고 SLEEP을 올려 PH/EN 모드로 시작한다. 10kΩ 풀다운으로 부팅·리셋 시SLEEP/EN을 낮게 유지한다. FAULT에는10kΩ 풀업을 둔다.
- 출고 약2A 제한은 이 모터에 너무 크다. 5V SLEEP과 기본 VREF의10kΩ 풀업 조건에서 VREF→GND **866Ω** 추가를 시작값으로 사용하면 대략0.16A 제한이다. 전류가 부족하면 무작정 올리지 말고 마찰·부하를 먼저 측정한다. 0.16A는 끼임 안전 인증값이 아니다. [DRV8876 설정](https://www.pololu.com/product/4036)
- 잠금:12V+→코일→IRLZ44N Drain, Source→GND. Gate220Ω 직렬/47kΩ 풀다운. 1N4007은 **솔레노이드** 양단 역병렬, 띠가12V+다. 양방향 모터 양단에 단일 플라이백 다이오드를 추가하면 한 방향에서 단락되므로 사용하지 않는다.
- 12V에470µF/25V, 5V에47µF, HX711근처10µF+100nF. 모터·코일 전류는 센서GND와 분리 배선해 입력 근처에서 합친다.
- Nano5V핀에 안정화5V 공급. USB와 외부5V 동시 연결 시 역급전 분리 확인. HX711 #5974의 VCC와 VIO에5V, E+/E-를 셀 여자에 사용한다. 샘플레이트10SPS. [HX711 핀 설명](https://learn.adafruit.com/adafruit-hx711-24-bit-adc/pinouts)

## 제안 핀맵

|Nano|연결|
|---|---|
|A0 / A1|HX711 DOUT / SCK|
|D5|DRV8876 EN/PWM|
|D8|DRV8876 PH/방향|
|D4|DRV8876 SLEEP, 기본LOW|
|D2|DRV8876 FAULT,10kΩ 풀업|
|A6|DRV8876 CS, 직렬1kΩ/100nF 필터, 환산약2.49V/A|
|A7|12V 전압100kΩ/33kΩ 분압|
|D7|잠금 IRLZ44N gate|
|D9 / D10|BLE TX→Nano RX / Nano TX→BLE RX|
|D11 / D12|BLE CTS / RTS; 흐름제어 지원 필요|
|A4 / A5|MCP23017 SDA/SCL,5V,주소0x20|
|D3|로봇 정지·덮개 격납 등으로 결정한 외부 허가 입력용 예약|
|D6|상태LED 또는 별도 표시용 예약|

MCP23017 GPA0/1=왼쪽/오른쪽DOWN, GPA2/3=왼쪽/오른쪽UP, GPA4=래치전진, GPA5=래치후퇴, GPA6=덮개닫힘, GPA7=덮개격납, GPB0=전면패널, GPB1=전장보호판. 나머지는 예비. D2F-01L의 COM·NC·NO를 정비기판으로 인출하고, 필요 접점+풀업으로 정상 상태와 단선을 구분한다. 단일 접점만으로 단락 고장까지 진단되지는 않는다.

## 동작

1. 로봇 정지와 인증된 열기 요청 확인 → 잠금 후퇴 확인. 사용자가 R3 도어를 세워 슬롯에 격납한다.
2. 격납 접점, 패널·보호판, 정상전원, 양쪽DOWN 일치를 확인한다. 틀리면 승강 금지. 격납 후에는 잠금 코일을 끄며 승강 동안 계속 통전하지 않는다.
3. 사용자가 상승을 요청하면 PWM을 천천히 증가시킨다. 두UP 접점, 전류,FAULT,시간을 함께 감시한다. UP하나만 감지되면 즉시 정지하고 비틀림 고장으로 유지한다. 자동 반복하지 않는다.
4. 한 번의 구동을6초 이내로 제한하고, 통전한 시간의4배 이상 휴지한다. 예:6초 동작이면24초 휴지. 내부끝단스위치는 백업이며, 강제 스톨로 위치를 만들지 않는다.
5. 하강은 명시적 요청을 누르고 있는 동안 수행하고, 사용자가 손을 치웠음을 확인한다. 종이가 없어졌다고 자동으로 내리거나 닫지 않는다. 과전류·통신/I2C타임아웃·리셋·스위치 불일치면 EN=LOW/SLEEP=LOW.
6. 양쪽DOWN과 모터정지 확인 → 최소3초 안정화 → 로봇정지 유지 및 R3의 잡음/ADC신선도 조건을 통과한 무게만 유효화.
7. 바닥이 완전히 내려간 상태에서만 사용자가 도어를 꺼내 닫는다. 기존R3처럼 닫기 직전 잠금핀을 후퇴시킨 뒤 닫힘·핀전진을 확인한다.

애니메이션은 순서를 보여 주는 기구 예시다.24fps의240프레임을 실제 열림 대기시간·듀티 제한 타이머로 사용하지 않는다. 실제 운전은 위센서 조건과 휴지 시간을 따라야 한다. R3의 watchdog/솔레노이드 통전제한을 보존하고 승강 채널에도 독립된 타임아웃을 추가해야 한다.

R3-LIFT의 상승 상태 계량은 합격 대상으로 잡지 않는다. 기본 사용은 **하강·정지 때 내용물 감지, 도어 격납 뒤 종이를 꺼내기 위해 상승**이다. A4약5g검출은 ADC비트 수로 보증할 수 없으며 실측한다.
