# R4 출력 준비본 — 220 × 220 mm 베드

**`STL_print/`의 STL을 mm / 100% 크기로 가져와 출력한다.** 한 STL이 한 개의 닫힌 고체이며, 모든 부품은 Z=0에 놓이고 최대 216 × 216 mm 안에 들어간다. 베드 가장자리에 최소 2 mm씩 여유를 둔다. 프린터 기종을 지정하지 않았으므로 G-code와 기종별 온도 프로파일은 만들지 않았다.

- [출력용 Blender](smart_lock_box_r4_print.blend): `PRINT_PLATES_220mm` 장면의 P001, P002… 컬렉션마다 **서로 다른 한 장의 베드**다. 전체 격자를 한 번에 출력하지 않는다.
- 같은 파일의 `ASSEMBLED_PRINTED_PARTS` 장면은 출력된 부품의 원래 조립 위치를 보여 준다.
- [회로 없는 조립 모델](r4_mechanical_no_circuits.blend): 보드·배선은 제거했고 모터·금속 기구 부품은 조립 참조용으로 남아 있다.
- [출력 목록 CSV](PRINT_LIST.csv) · [출력 제외 목록](NON_PRINTED_PARTS.csv) · [기하 검사와 파일 해시](print_manifest.json)

## 출력 시작 설정

| 항목 | 시작 설정 |
|---|---|
| 재료 | PETG, 기구 확인용 시제품 |
| 노즐 / 적층 높이 | 0.4 mm / 0.15–0.20 mm |
| 외벽 | 기본 4줄; 모델의 1.2 mm 앞뒤 종이 턱은 3줄 |
| 상하부 | 5층 이상 |
| 내부 채움 | 몸체·브래킷 35–45%; 3 mm 종이판·겹침 이음·작은 지지부는 100% |
| 서포트 | 겹침 이음의 뜨는 선반, 브래킷과 가로 구멍을 슬라이서에서 확인; 필요한 곳만 베드에서 지지 |
| 브림 | 2 mm부터 검토. 가장 큰 종이판 폭은 215.5 mm이므로 넓은 브림은 220 mm 베드를 벗어날 수 있음 |
| 온도 / 속도 | 사용하는 PETG와 프린터의 실제 프로파일 적용 |

부품별 회전은 낮은 높이와 넓은 바닥 접촉면을 기준으로 정했다. 크기를 줄이기 위해 축소하지 않았다. 구멍은 CAD 공칭 치수이며 축·부시 구멍은 시험편으로 맞춤 상태를 확인하고 필요하면 리밍한다.

## 분할 부품 조립

1. CSV의 같은 `source`에 해당하는 `__01`, `__02` 등의 조각을 모은다. Blender 조립 장면에서 위치를 확인한다.
2. 8 mm 계단 모양 겹침 이음을 맞춰 본다. 이음 여유는 0.15 mm다. 브림·서포트 잔여물을 제거하며 외곽 크기는 유지한다.
3. PETG에 적합한 접착제의 사용법에 따라 접합면을 준비하고 접착한다. 접착용 이음이므로 끼워 두기만 해서는 안 된다. 평평한 판 위에서 원래 외곽 치수를 맞춘 채 경화시킨다.
4. 종이판 윗면의 이음은 종이가 걸리지 않도록 빈틈을 메우고 평평하게 마감한다. 낮은 쪽 턱은 바닥에 붙은 일체형 ㄴ자이며 분할 이음도 틈 없이 접착한다.
5. A4 한 장과 10 mm 종이 묶음을 올려 낮은 쪽에서 빠지지 않는지 확인한다. 손으로 개폐·승강 전 구간을 천천히 움직여 본 뒤 모터를 연결한다.

몸체·뚜껑·종이판·커버·일부 브래킷은 출력 대안이다. 금속축, 운반 손잡이, 계량 프레임, 저울 지지부, 잠금 부품, 힌지 허브/암 등 금속으로 유지할 부품과 모터·베어링·나사는 `NON_PRINTED_PARTS.csv`에 있다. 출력한 몸체나 접착 이음의 운반 하중은 아직 시험하지 않았다. 금속 부품 도면과 구매 부품 사양은 상위 폴더를 참조한다.

STL의 닫힌 면·부피·크기·단위·분할 형상은 소프트웨어로 검사했다. 실제 슬라이싱, 첫 출력의 공차, 접착 강도 및 실물 구동은 별도 확인 대상이다.
