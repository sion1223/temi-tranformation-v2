# R4 AUTO LIFT — 자동 뚜껑 + 상승·경사 종이 받침

요청한 동작을 **뚜껑 모터 1개 + 받침 모터 2개 + 기존 잠금 솔레노이드**로 설계했다. 앞에서 보았을 때 뚜껑이 있는 **왼쪽이 낮고 오른쪽이 높다**. 종이 받침 전체가 먼저 올라오고, 오른쪽을 더 올려 12° 기울인다.

**설계 및 시뮬레이션 단계다. 실제 모터를 연결한 구동시험, 테미 장착시험, 부하·끼임·단전시험은 아직 하지 않았다.** 제어 코어는 호스트에서 시험한 참고 구현이며, 기존 Nano에 그대로 업로드하는 완성 펌웨어가 아니다.

## 기존 R3에서 바뀐 구조

기준 파일은 `../smart_lock_box_r3/smart_lock_box_r3.blend`이며 기준 커밋은 `719c6429582e862e695bbf21333185b1ba9c1987`이다. 원본 R3 파일과 기존 펌웨어는 보존한다. 원본 해시는 `parameters.json`에 기록했다.

| 항목 | R4 설계 |
|---|---|
| 뚜껑 | 왼쪽 X=9, Z=74의 고정 Y축에서 **105°** 자동 회전 |
| 기존 수동 격납 | **세운 뒤 아래로 밀어 넣던 동작은 사용하지 않는다.** 고정 힌지판·8mm 축으로 교체한다. 열림 상태 높이가 R3보다 커진다 |
| 받침 | 기존 213.5 × 308 × 3mm 판 크기 유지. 앞뒤 가이드로 두 축을 지지 |
| 왼쪽 받침 끝 | Z=51 → **83.54mm**, 약 **32.54mm 상승** |
| 오른쪽 받침 끝 | Z=51 → **127.93mm**, 약 **76.93mm 상승** |
| 받침 경사 | 수평 상승 35mm 후 **12°**, 뚜껑 쪽으로 내려가는 방향 |
| 계량 | 기존 판의 로드셀 직결을 풀고, 로드셀에 고정한 새 계량 프레임 위에 판을 얹음. 승강 시 분리, 복귀 시 재안착 |
| 종이 수납 | A4 210 × 297mm. 모델의 종이 묶음은 높이 10mm. 경사 아래쪽에 15mm 이탈 방지 턱 |
| 기구 공간 | 255 × 324 × 78mm는 **기존 본체 크기**. 모듈 포함 닫힘 **293 × 421 × 190mm**, 열림 **약 332.5 × 421 × 347.5mm**. 좌표 범위는 `validation/envelopes.json` 참고 |

뚜껑이 열렸을 때 종이를 집기 좋게 상승시키는 설계다. 종이를 한 장씩 자동 분리하거나 배출하는 급지기는 아니다. 종이 묶음이 사라졌다고 곧바로 닫지 않으며, 닫기 요청과 손 감지 상태를 확인한다.

## 자동 순서

1. 테미 정지와 유효한 열기 요청 확인 → 기존 솔레노이드로 잠금핀 후퇴 확인.
2. M1이 뚜껑을 105°까지 열기. 힌지의 독립 위치센서와 열림 스위치를 모두 확인.
3. M2/M3가 먼저 유격을 없앤 뒤 받침을 수평으로 35mm 올리기.
4. M2 위치를 유지하고 M3를 더 움직여 오른쪽을 높게, 12°로 기울이기.
5. 닫기 요청 시 경사 해제 → 수평 하강 → 계량 프레임 안착 → 두 축을 더 내려 유격 확보.
6. 받침 안착과 네 홈 스위치를 확인한 뒤 M1으로 6°까지 닫기.
7. 잠금핀 후퇴를 다시 확인 → 마지막 6° 닫기 → 코일 해제 → 닫힘 및 핀 전진 확인.

열림 명령부터 받침이 최종 위치에 도달하기까지 명목 약 **31초**다. 빠른 동작보다 10°/s 뚜껑, 4mm/s 승강 기준으로 설계했다. 애니메이션의 시간은 명목 궤적이며 실제 제어의 완료 조건은 **센서 값**이다.

## 조립 변경점

1. 기존 숄더볼트와 수직 격납 가이드를 고정 힌지판·8mm 축·베어링·클램프 허브로 교체한다. 모터 축에 뚜껑의 하중을 직접 걸지 않는다.
2. 앞쪽 M1 브래킷, 20T/60T 풀리, 타이밍 벨트와 장력 조정구를 설치한다. 뒤쪽 각도 스토퍼, 독립 힌지 센서, 개방 보조 스프링·댐퍼를 실물 선정한다.
3. 왼쪽과 오른쪽에 각각 앞뒤 Tr8×2 나사 2개를 설치한다. 한쪽당 모터 1개가 타이밍 벨트로 앞뒤 나사를 함께 돌린다. 앞뒤에는 별도 가이드와 위치센서가 있다.
4. R3 전장 보호판·앞뒤 벽·상단 턱의 승강축 통로를 수정한다. 기존 상단 턱이 종이 판의 상승 경로에 걸리므로 안쪽 돌출을 제거한다. 슬롯과 벨트 경로는 가동 커버/벨로스로 보호한다.
5. 왼쪽 허브 회전 공간을 확보하고 닫힘 리드 센서와 자석을 오른쪽으로 3.5mm 옮긴다. 오른쪽 벽에도 센서 포켓을 가공한다.
6. 로드셀 가동 스페이서 상면을 Z45로 바꾸고 새 계량 프레임을 M6 두 개로 고정한다. 종이 판은 프레임 위에 안착한다. 계량 시 고정 가이드·배선·승강축에 기대면 안 된다.

`parts/`는 가공 후보 형상이다. 금속 축·판재·베어링·모터까지 모두 3D 프린터로 출력하는 묶음이 아니다. 나사 체결 위치, 재료 강도, 프린터 공차, 구매품 허브/브레이크/센서의 최종 장착 도면은 실물과 대조해야 한다. 308mm 판·348mm 축은 일반 220mm 프린터 베드에 들어가지 않는다.

## 재생성 및 검사

저장소 루트에서 실행한다. Blender 4.5.3 LTS로 재생성했다.

```bash
blender -b --python basket/smart_lock_box_r4/build_r4.py
blender -b --python basket/smart_lock_box_r4/validate_r4.py
blender -b --python basket/smart_lock_box_r4/render_r4.py
python basket/smart_lock_box_r4/package_review.py
g++ -std=c++17 -Wall -Wextra -Werror basket/smart_lock_box_r4/tests/controller_test.cpp -o /tmp/r4_test
/tmp/r4_test
```

R3 원본은 Blender 5.2에서 저장되어 4.5.3에서 읽을 때 버전 경고가 발생한다. R4는 원본 동작을 지우고 새 애니메이션을 만들며, 그대로 사용한 메시의 외곽을 원본 `object_inventory.json`과 대조했다. 원본 파일 자체는 수정하지 않았다.

검사는 표면 교차와 공칭 좌표를 대상으로 한다. 실제 처짐, 마찰, 종이 말림, 나사 유격, 타이밍 벨트 파손, 바람, 테미 헤드·팔·주행 중 간섭은 별도로 확인해야 한다. 검증 범위와 제외한 조인트 접촉은 결과 JSON에 함께 적었다.
