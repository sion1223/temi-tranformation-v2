# 앞뒤 운반 손잡이

R4의 고정 바닥판에 운반 손잡이 2개를 추가했다. 손잡이 발판을 본체 아래로 연장해 바닥판에 직접 볼트로 연결한다. 뚜껑, 종이 받침, 로드셀, 분리식 전장 패널에는 연결하지 않는다. 기존 모터 수와 자동 동작 궤적은 그대로다.

| 항목 | 공칭 치수·좌표 (mm) |
|---|---|
| 그립 | 강재 원봉 Ø14, 직선부 길이 107, 양끝 R7 둥근 마감 |
| 그립 중심 | 앞 Y=-66 / 뒤 Y=390, Z=45 |
| 다리 중심 | X=92, 199 / 원봉 Ø11 |
| 파지 공간 | 다리 안쪽 간격 96, 그립 밑면~발판 윗면 38 |
| 발판 | 각 손잡이당 2개, 폭 12 × 길이 108 × 두께 4 |
| 발판 Z 범위 | -4~0, 기존 바닥판은 0~6 |
| 앞 발판 Y 범위 | -74~34 |
| 뒤 발판 Y 범위 | 290~398 |
| 앞 체결구멍 | (X,Y)=(92,12), (92,28), (199,12), (199,28) |
| 뒤 체결구멍 | (X,Y)=(92,312), (92,296), (199,312), (199,296) |
| 구멍 | Ø4.5 관통, 바닥판 윗면 Ø8.6의 90° 카운터싱크 |
| 체결품 | M4×20 접시머리 볼트 8개, Ø9×1 와셔 8개, 풀림 방지 너트 8개 |

`parts/R4_carry_handle_front.stl`, `parts/R4_carry_handle_rear.stl`은 원봉·발판을 용접한 조립체 형상이다. `parts/R3_base_255x324.stl`은 구멍을 추가한 바닥판이다. 모든 STL은 mm이며 조립 좌표를 유지한다. 금속 제작용 참고 형상으로, 운반 하중을 받는 손잡이를 플라스틱 출력품으로 대체하지 않는다.

볼트 머리를 바닥판 윗면과 평평하게 설치하고, 손잡이 발판 아래에 와셔와 풀림 방지 너트를 넣는다. 원봉과 발판 접합부는 용접하고 손이 닿는 모서리를 다듬는다. CAD의 볼트·너트는 구매품 공간 표시이며 나사산·용접 비드는 생략했다. 실제 구매품 머리 높이와 너트 높이, 나사 물림 길이를 조립 전에 맞춘다.

손잡이는 앞뒤 모터와 기둥 사이의 공간을 사용한다. 발판은 모터 옆, 그립은 기둥 바깥에 있어 구동부를 손잡이로 잡을 필요가 없다. 손잡이가 포함된 공칭 전체 크기는 닫힘 293×472×190mm, 열림 약 332.5×472×347.5mm이다.

뚜껑을 닫고 받침을 내린 상태에서 앞뒤 손잡이를 함께 사용한다. 이 손잡이는 분리한 바스켓을 옮기는 용도이며 테미 로봇 전체를 들어 올리는 고리가 아니다. 금속 바닥판 재료·접합부·용접 품질을 포함한 실제 운반 하중 시험 전이므로 정격 운반 하중은 지정하지 않았다.
