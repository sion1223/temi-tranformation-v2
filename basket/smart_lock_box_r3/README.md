# 스마트 잠금 상자 R3-A4 — 단일 수납·이중 바닥 수정본

사용자 확정 요구: **상부 칸막이 제거, 전원·회로는 아래층, A4 한 장 감지**. A4 80 g/㎡는 계산상 4.9896 g이다. 최대 적재량은 미정이다.

**상태: CAD 및 소프트웨어 검사를 수행한 시제품 설계. 실물에서 A4 검출·잠금 강도·발열·테미 장착을 검증한 제품이 아니다.** 제작 전 실물 검수 항목은 `HARDWARE_ACCEPTANCE.md`를 따른다. 실측 데이터가 없는 항목은 합격으로 표시하지 않았다.

## 열 파일

- `smart_lock_box_r3.blend`: 편집 모델과 개폐 애니메이션. 1프레임 잠김, 24 해제, 48 수직, 72 격납, 108 닫기용 후퇴, 144 재잠금.
- `smart_lock_box_r3.glb`: 같은 모델의 미터 단위 공유 파일, 동시 재생 애니메이션 1개.
- `assembly_and_circuit_r3.pdf`: 이중 바닥 배치, 잠금, 전원·배선·핀, 조립 및 검증 범위.
- `drawings/`: 실제 수정 모델에서 렌더한 검사 이미지. `07_double_floor_exploded.png`는 구조 설명을 위한 분해도다.
- `BOM.csv`, `placement.csv`, `netlist.md`: 부품표, 위치, 배선표.
- `firmware/smart_lock_box/`: Nano 스케치와 동일 소스에 사용한 암호 라이브러리 일부.
- `validation/`: 실행한 기하·내보내기·펌웨어 검사 결과.
- `STL_print/`: 출력 후보 형상. `fabrication/`: 금속/판재/가공 부품의 형상 참고 STL. 길이 324 mm 부품은 보통 220 mm 베드에 들어가지 않는다. 모든 STL을 한 번에 그대로 출력하는 패키지가 아니다.

원본 `basket/smart_lock_box.blend`의 SHA-256은 패키지 R2와 같고 v2와 다르다. 기존 비교문에 있던 “바탕화면 파일은 v2”라는 설명을 현재 작업 폴더 파일에 적용하지 않았다. 원본 파일과 두 ZIP은 변경하지 않았다. 재생성용 `source_r2.blend`는 그대로 보존했다.

## 제안을 수정한 이유

| 이전 제안 | 이번 결정 |
|---|---|
| R2 잠금을 기반으로 개선 | 가로 핀과 금속 키퍼 개념을 유지. 잠금장치를 회전·하강시켜 아래 전장층으로 이동 |
| FSR을 12개에서 9개로 | 채택하지 않음. 종이 한 장은 FSR 보장이 어려우며 3점 지지 역시 지지 삼각형 밖 하중을 보장하지 않음 |
| 로드셀은 나중에 | 종이 감지가 필수여서 지금 단일점 로드셀 + HX711로 교체 |
| 작은 잠금 구역을 상부에 유지 | 상부 구역을 없앰. 키퍼만 적재판 오른쪽 틈으로 내려옴 |
| 3S 배터리 팩 이식 | 직결하지 않음. 3S는 충전 상태에 따라 전압이 달라지고 BMS는 충전기·12 V 안정화 장치가 아님. 배터리 미선정 |
| USB 5 V이면 래치 + 슈퍼캡 | 전력 예산·액추에이터·복귀 동작을 확인하지 않은 변경이라 보류 |
| 전면 정비 패널 보강 | 패널의 나사를 내부 수직 체결로 변경하고 외부 USB 개구 제거. 키퍼 나사도 도어 밑면에서만 접근 |
| 접이식 도어 | 힌지·가이드·새 잠금 경로·테미 헤드 위치가 달라지는 별도 기구이므로 이번 수정에 혼합하지 않음 |
| HMAC 도입 | 명령뿐 아니라 상태 응답도 HMAC으로 인증. PIN 평문 명령 삭제. 실제 앱 연동은 별도 구현 필요 |

## 실제 구조와 크기

좌표: X=폭, Y=앞→뒤, Z=바닥→위, mm.

| 구역 | 범위 / 의미 |
|---|---|
| 외형 | **255 × 324 × 78 mm**. A4 폭 확보를 위해 R2보다 X +12 mm |
| 상부 단일 적재판 | X 24~237.5, Y 8~316, Z 48~51. **213.5 × 308 mm** 평면 |
| 수납 높이 | 적재판 상면 51 → 도어 밑면 70 = **19 mm** |
| 고정 전장 보호판 | Z 41~44. 로드셀 가동 스페이서와 키퍼를 위한 개구만 존재 |
| 전원·회로층 | 바닥 상면 Z 6부터 보호판 아래 Z 41까지. MCU, 5 V 변환, HX711, BLE, 보호회로 및 잠금장치 배치 |
| 로드셀 | Z 14~36, 중앙 고정단/가동단 구조. 상판은 가동단으로만 하중 전달 |
| 과부하 스토퍼 | 정상 상판과 **초기 0.8 mm 비접촉 틈**. 실측 처짐에 맞춰 조정 |
| 격납 상태 | 최고 Z 약 252.2, 78 mm 상자 위 **174.2 mm 돌출**. 테미 헤드 간섭 미검증 |

종이가 고정벽·덮개·배선에 기대면 그 부분의 무게가 로드셀을 우회한다. 바닥 틈을 테이프나 단단한 패킹으로 연결하지 않는다. 라이너는 적재판과 같이 움직여야 한다. 종이의 말림·바람·로봇 진동은 실제 검출시험에 포함한다.

상판은 3 mm 알루미늄 기준 약 0.53 kg이며 스페이서·나사를 더한 무게도 로드셀 용량에 포함된다. 선정 기준품은 **Zemic L6D-C3-3kg-0.40B**다. 권장 플랫폼 250×350 mm 이내다. 3 kg는 센서의 총 하중 정격이며 상자의 허용 적재량을 뜻하지 않는다. 펌웨어의 **1,000 g 순하중 한도는 임시 제한**이다. 최대 물품 무게를 결정한 뒤 구조·가속·충격을 포함해 다시 선정한다.

로드셀 외형 130×30×22 mm, 양 끝 12 mm 위치 및 가로 15 mm 피치의 M6 구멍은 제조사 Rev8 도면을 참고했다. 최신 Rev12의 정격과 플랫폼 크기를 대조했다. **실제 구매품의 구멍, 케이블 출구, 하중 화살표, 체결 토크·볼트 길이를 최종 도면과 맞춰야 한다.** 셀 본체는 구매품 외형이며 직접 제작하는 부품이 아니다.

## 아래층 잠금

5065 핀은 X축으로 움직인다. 잠김 끝 X242, 후퇴 끝 X237.7, 스트로크 4.3 mm. 키퍼 판 X239~240.5와 교차해 상승을 막는다. 명목 해제 간격은 1.3 mm다.

키퍼를 길게 내렸더니 첫 수정에서는 **3.25°부터 오른쪽 벽에 충돌**했다. 이 결과를 기록하고 벽 안쪽 X248까지 회전 여유 포켓을 가공해 해결했다. 해당 포켓 바깥에는 7 mm 벽 두께가 남지만, 그 사실만으로 강도나 방도 성능을 보장하지 않는다. 최종 전체 도어 경로와 애니메이션을 재검사했다.

키퍼의 M2.5 고정 나사는 도어 밑면에서 체결하며 바깥 상면에 2 mm 재료를 남긴다. 외부 전면 나사를 제거하고 패널 체결 나사를 내부로 옮겼다. USB는 패널 안쪽에 있다. 단, 이 변경은 인증된 금고/방도 구조가 아니며 출력물 파괴·스위치 우회·서비스 배선 공격까지 검증한 것은 아니다.

**닫을 때도 `CLOSE` 명령으로 후퇴를 확인한 다음 도어를 내린다.** 도어 자중이 경사 핀 스프링을 이겨 자동으로 닫힌다고 가정하지 않는다. 닫힘 + 핀 전진 + 비후퇴 + 패널/전장판 정상 상태가 확인돼야 잠김이다. 500 ms 안에 후퇴 미확인 시 고장, 최대 2초 통전, 통전 종료 후 최소 6초 휴지다. Timer1 비교 인터럽트가 D7을 차단하고 1초 watchdog도 사용한다. 하드웨어 독립 안전 타이머나 MOSFET 단락 보호를 인증한 구조는 아니다.

## 전원과 센싱

기준은 **안정화 외부 12 V DC**다. T1A 퓨즈·SB310 역극성 보호·IRLZ44N·220 Ω 게이트 저항·47 kΩ 풀다운·코일 양단 1N4007을 유지한다. 내부 전원 장치는 바닥층의 12→5 V 변환 및 보호회로다. 로봇 포트 전압과 전류는 확인되지 않았고 배터리는 실제로 넣지 않았다. 선택 공간은 CAD에서 숨겨진 참고 영역으로만 표시했다.

배터리 자립형이 필요하면 선정된 보호 팩 → 퓨즈 → 12 V 승강압 안정화 → 현재 입력을 사용한다. 충전은 그 팩의 전용 충전기를 사용하고 충전기/BMS/역전류 차단/고정 브래킷·발열까지 추가 검증해야 한다. 이번 BOM에 미선정 배터리를 완성품처럼 넣지 않았다.

HX711은 **10 SPS, 채널 A, gain 128**. 로드셀 권장 여자전압에 맞춰 AVDD/E+에 깨끗한 5 V를 쓰는 회로를 명시했다. 일부 HX711 모듈의 약 4.3 V 여자 출력을 그대로 5 V라고 간주하지 않는다. 기존 Nano ADC/FSR MUX 회로는 제거한다.

15초 초기 대기, 로봇 정지 신호 1초 지속, 새 샘플 20개, 0.8 g 이하 창 내 최대-최소, 최근 ADC 데이터, 코일 종료 후 3초가 모두 필요하다. 임시 적재 임계값은 ON 3 g / OFF 1 g이며 유지시간을 적용한다. 잡음이 커지거나 ADC가 안 오면 `weight_valid=0`이다. **24비트 ADC라는 이유로 5 g 검출을 보증하지 않는다.**

## 인증·보정·앱 연결

기존 `STOPPED <PIN>` / `UNLOCK <PIN>` 명령은 지원하지 않는다. `CHAL <verb>` → 상자 nonce → `AUTH <HMAC-SHA256>`로 1회 명령을 인증한다. 재전송, 채널 바꾸기, 명령 바꾸기, 2초 이상 지연한 응답을 거절한다. 오류 5회면 30초 제한한다. 상태 응답도 nonce에 묶어 서명한다. BLE 통신 자체의 암호화, 도청에 대한 상태 기밀성, 전파 방해 방어를 구현한 것은 아니다.

256비트 키는 호스트의 OS 난수원으로 만들고 **도어·전면 패널을 연 USB 정비 상태에서만** 등록/교체한다. 키를 코드·BOM·ZIP에 넣지 않는다. 비밀번호 변경 대신 장치 키를 교체하며 사용자 로그인/PIN 정책은 앱에서 처리한다. nonce는 키 기반 HMAC과 EEPROM 부팅 세대 번호/카운터로 생성한다. EEPROM은 두 슬롯의 CRC/반전값/최종 커밋 바이트를 검사하며, 새 부팅 번호 저장·읽기 검증에 실패하면 인증을 시작하지 않는다. 같은 키로 카운터를 초기화하는 재등록은 거부한다. EEPROM 스냅샷 복원이나 물리적인 키 추출까지 막는 보안 하드웨어는 아니다.

```text
python tools/box_client.py keygen --key-file C:/private/r3-key.json
python tools/box_client.py provision --key-file C:/private/r3-key.json --port COM5
# 등록 후 상자 재부팅. 도어/패널을 연 USB 정비 상태, 로봇 정지:
python tools/box_client.py calibrate --key-file C:/private/r3-key.json --port COM5 --bench-stationary
```

보정은 **빈 판 → 검증된 500 g 분동**의 두 단계다. 하나의 serial 연결을 유지한다. 빈 상태 캡처만으로 보정을 유효화하지 않는다. 저장된 영점·감도·CRC를 다음 부팅에 읽는다. 물건이 있는 채로 켜도 자동 영점 보정을 하지 않는다. 보정 후 패널을 닫고 인증된 `RESET`으로 탬퍼 고장을 해제한다.

`tools/box_client.py`는 **벤치용 참조 클라이언트**이며 테미 앱의 교체 구현이 아니다. `--bench-stationary`는 사람이 정지를 확인한 시험용이다. 실제 앱은 테미 속도/이동 상태에서 정지를 판정해 0.5초 간격으로 인증된 `STOPPED`를 보내고, 이동 시작 시 `MOVING`을 보내야 한다. 시작 직전에 새로 인증한 `ready_to_travel=1`을 확인한다. 이동 중에는 무게 판정이 무효이므로 `containment_ok`를 별도로 감시한다. 상태가 없거나 오래됐으면 이동을 허가하지 않는다. Nano만으로 테미 주행을 정지시키지는 못한다.

상태 서명 원문은 `R3-RESP|<nonce hex>|S ...`이다. 필드 순서와 엄격한 검증은 `box_client.py`의 `FIELDS`, `verify_state`, `may_start_travel`을 따른다. 임의로 수신한 과거 STATUS 문자열을 근거로 움직이면 안 된다.

## 검증과 한계

`validation/summary.json`이 실행 결과의 기준이다. 기하 검사는 접촉력·탄성 변형 해석을 대신하지 않으며, “의도한 잠김 접촉”과 “해제 중 충돌”을 구분한다. 실제 프레임의 핀 애니메이션도 함께 검사했다. 정지 조립 간섭은 나사 체결 및 구매 솔레노이드 내부 외형 중첩을 이름별로 명시해서만 허용했다.

소프트웨어 시험은 실제 제어/인증 헤더와 실제 `.ino`를 호스트에서 컴파일하고, 하드웨어 I/O만 모의했다. 시뮬레이션 종이 신호 90회 시험은 합성 데이터이지 실물 종이 시험 결과가 아니다. AVR용 실제 보드 컴파일도 별도로 수행했다. 보드에 업로드하거나 실물 로봇을 움직이지 않았다.

**실물 출시 조건:** 잠금 인장/닫기 시험, 실제 셀 장착/최대 적재 확정, 5 g 분동 9지점 시험, A4 한 장 적재·회수 반복, 30분 영점 드리프트, 재부팅·전압 강하·통신 단절·DOUT 단선/단락, watchdog 부팅 복구, 테미 헤드와 장착 간섭. 판재·가이드 강도와 가이드 상단 1 mm 구간도 재료/하중 시험 대상이다.
