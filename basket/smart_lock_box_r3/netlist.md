# R3-A4 회로 및 핀 연결

이 문서가 R3 배선의 기준이다. R2의 12채널 MUX/FSR 배선을 사용하지 않는다. PCB 파일이 아닌 점대점 회로 연결 명세이며, 보드별 핀 위치는 실제 구매품에서 확인한다.

## 전원·잠금 구동

| 출발 | 도착 / 부품 |
|---|---|
| J0 +12 V 입력 | F1 T1A → D0 SB310 애노드; D0 캐소드 → V12_PROTECTED |
| J0 GND | 전원부 STAR_GND |
| V12_PROTECTED | 코일 + / 470 µF 25 V + / Pololu D24V10F5 VIN |
| 코일 - | IRLZ44N Drain |
| IRLZ44N Source | STAR_GND |
| Nano D7 | 220 Ω → Gate |
| Gate | 47 kΩ → Source/GND |
| D1 1N4007 | 캐소드 띠 → 코일 +; 애노드 → 코일 -/Drain. 코일 가까이 설치 |
| D24V10F5 VOUT | +5 V → Nano 5V / BLE용 3.3 V LDO / HX711 5 V 계통 |
| VOUT GND | STAR_GND. 센서 GND에 코일 전류가 흐르지 않게 분리해 공통점에서 결합 |
| +5 V | 47 µF 및 각 보드 100 nF. Nano VIN 미연결 |
| USB | 외부 5 V와 중복 급전을 막는 VBUS 차단/데이터용 연결. 클론 Nano 전원 OR 회로를 가정하지 않음 |

## HX711·로드셀

HX711의 내부 4.3 V 조정 회로를 쓰지 않고 데이터시트의 **외부 아날로그 전원 방식**을 사용한다. 모듈이 이에 맞게 구성 가능한지 구매 전에 확인한다.

| HX711 신호 | 연결 |
|---|---|
| VSUP, DVDD | +5 V |
| AVDD | +5 V → 저 DCR 페라이트 → V5_ANALOG. AVDD에 10 µF + 100 nF, 같은 전원으로 셀 E+ 여자 |
| AGND | 센서 아날로그 GND → STAR_GND |
| VFB | GND, BASE는 NC. 외부 전원 사용 시 내부 레귤레이터 바이패스 |
| E+ / E- | L6D 빨강 / 검정 |
| INA+ / INA- | L6D 초록 / 흰색. 각 100 Ω 직렬, INA+와 INA- 사이 100 nF |
| Shield | 트레이 쪽 아날로그 GND에 한쪽 끝만. 셀 본체와 실드 연결을 임의로 가정하지 않음 |
| DOUT | Nano D8 (INPUT_PULLUP) |
| PD_SCK | Nano D9, 초기 LOW, 25펄스로 채널 A/gain128 선택 |
| RATE | GND = 10 SPS |
| XI / XO | XI GND, XO NC (내부 발진기) |
| INB+, INB- | 사용하지 않는 채널, 함께 AGND 연결 |

아날로그 5 V는 실제 로드셀 여자 단자에서 측정한다. 로드셀을 일반 3점 FSR처럼 여러 군데에 지지시키지 않는다. 가동단 아래에 전선·기판·접착제·고정 나사가 닿으면 측정이 틀어진다.

## Nano 입력과 통신

| 핀 | 연결 | 판정 |
|---|---|---|
| D2 | 후퇴 확인 SW 접점 ↔ GND | LOW일 때 실제 키퍼 해제 간격 ≥0.3 mm가 되도록 레버 조정 |
| D3 | 도어 닫힘 리드 ↔ GND | LOW=닫힘 |
| D4 | 격납 리드 ↔ GND | LOW=도어 하부 격납 |
| D5 | 전진 확인 SW 접점 ↔ GND | LOW=핀 전진 |
| D6 | 1 kΩ → 상태 LED → GND | 정상 잠김 표시 |
| D7 | MOSFET Gate 220 Ω | HIGH=코일, Timer1이 최대 2초 후 강제 LOW |
| D8 / D9 | HX711 DOUT / SCK | 기존 MUX에 연결하지 않음 |
| D10 | BLE TX | Nano SoftwareSerial RX |
| D11 | 1 kΩ → BLE RX, RX → 2 kΩ → GND | 5 V TX를 약 3.33 V로 분압 |
| D12 | 전장 보호판 장착 확인 접점 ↔ GND | LOW=장착. 열림/선 끊김은 탬퍼 고장 |
| A3 | 전면 패널 닫힘 확인 접점 ↔ GND | LOW=장착. 열림/선 끊김은 탬퍼 고장 |
| A6 | V12_PROTECTED → 100 kΩ → 노드; 노드 → 33 kΩ → GND; 노드 → 1 kΩ → A6; A6 → 100 nF → GND | 보호된 입력 전압 감시. 내부 배터리 잔량계가 아님 |
| A0,A1,A2,A4,A5,A7 | 미사용 | 센서 추가용으로 임의 연결하지 않음 |

D2/D3/D4/D5/D12/A3은 INPUT_PULLUP. 접점이 닫혀 GND가 연결될 때만 해당 정상 신호를 인정한다. NC/NO라는 접점 이름만 보고 논리를 정하지 말고 실제 장착·후퇴·전진 상태와 단선 상태를 모두 측정한다. 코일 통전 중 패널/전장판의 원시 입력 열림은 디바운스 대기 전 차단한다.

BLE는 3.3 V LDO(MCP1700-3302 등, 입/출력 1 µF)를 통해 전원 공급한다. HM-10 이름만으로 공급전압·UART 전압·페어링 보안을 가정하지 않는다. 정확한 모듈은 아직 미선정이다.

## 커넥터

| 커넥터 | 순서 | 주의 |
|---|---|---|
| J1 2P | V12_PROTECTED, Drain/coil return | 코일 전류용. 셀/센서 커넥터와 다른 키 |
| J2 8P | D2,GND,D3,GND,D5,GND,D4,GND | 잠금/도어/격납 상태 |
| J3 5P | E+,E-,A+,A-,Shield | 차폐 로드셀선. 색보다 제조사 배선표 우선 |
| J4 4P | D12,GND,A3,GND | 보호판/패널 탬퍼 |

전장층 정비: 도어 개방 → 전원 차단 → 적재판 가동단 체결 해제 → 적재판 수직 분리 → 내부 보호판 및 패널 나사 해제 → 커넥터 분리. HX711과 셀의 차폐선에 장력을 주지 않는다. 정비 뒤 영점·감도·반복성을 다시 검사한다. 기존 R2의 “외부 나사 두 개만 풀어 슬라이드 인출” 절차는 폐기했다.
